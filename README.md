## Why RISCAN exists

RISCAN was not created to become another online hardware store.

It exists to build trust.

Every decision inside the platform must increase transparency,
accuracy and reliability.

If information is uncertain,
we say that it is uncertain.

If delivery is delayed,
we tell the customer before they ask.

Trust is our product.

Hardware is only what we deliver.

---

## Principles

1.
Reputation is worth more than revenue.

2.
Never promise what cannot be verified.

3.
Data before opinions.

4.
Simple systems survive longer.

5.
Minimalism is respect for the user's time.

6.
Automation helps people.

It never replaces responsibility.

7.
Every line of code should make the system simpler.

8.
Every day we move the project forward.

Even if the progress is small.
